# advinhacao_v1
Jogo de Adivinhação em Python

Um jogo simples de adivinhação de números desenvolvido em Python para praticar conceitos fundamentais de lógica de programação e controle de fluxo.

🚀 Sobre o Projeto

O objetivo do jogo é tentar adivinhar um número secreto escolhido pelo programa. A lógica principal é construída utilizando estruturas condicionais (if, elif e else) 
para comparar o palpite do jogador com o valor correto e fornecer feedback em tempo real.

✨ Funcionalidades

🎲 Geração de número: O programa escolhe/define um número para o jogador adivinhar.

💬 Feedback dinâmico: Utiliza if e else para avisar se o palpite foi muito alto, muito baixo ou correto.

💻 Interface simples: Executado diretamente no terminal/console.

🛠️ Tecnologias Utilizadas

Linguagem: Python 3

Estruturas Principais: Condicionais (if / elif / else) e entrada de dados (input()).
